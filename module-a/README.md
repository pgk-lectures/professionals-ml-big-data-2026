## Важно: файлы src — это эталон, а не то, что дадут на чемпионате

В этом репозитории уже есть:

~~~text
src/01_download_tracks.py
src/02_build_dataset.py
src/03_make_maps.py
...
~~~

Они нужны как **эталонное решение для обучения**.

На чемпионате эти Python-файлы организаторы не выдают: участник должен написать программу самостоятельно на основе задания и предоставленных данных.

Поэтому рекомендуемый способ тренировки:

1. прочитать очередной критерий в статье;
2. создать/написать соответствующий файл самому;
3. запустить и проверить результат;
4. только после этого открыть готовый файл в `src/` и сравнить решения.

Названия `01_download_tracks.py`, `02_build_dataset.py` и т. д. — тоже наша учебная структура, а не требование чемпионата.

## Быстрый запуск эталонного решения

Если нужно проверить, что учебный pipeline в целом работает:

~~~bash
cd module-a

conda env create -f environment.yml
conda activate professionals-ml

docker compose -f compose.yml up -d

export DB_HOST=localhost
export DB_PORT=5432
export DB_NAME=professionals
export DB_USER=postgres
export DB_PASSWORD=postgres

bash run.sh
~~~

`run.sh` прогоняет все **20 учебных маршрутов** через полный pipeline.

Для подготовки к чемпионату лучше не начинать с `run.sh`: сначала пройти [пошаговую статью](../docs/module-a.md), где показано, **как написать каждый этап самостоятельно и зачем он нужен**.

Скрипты специально разбиты по этапам, чтобы при ошибке можно было перезапустить только нужную часть.
