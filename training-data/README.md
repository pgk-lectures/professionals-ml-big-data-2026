# Тренировочные данные

Эти данные подготовлены специально для обучения по модулю А.

## Важно

- это **не официальные данные чемпионата**;
- маршруты синтетические, но используют реалистичные географические координаты;
- использовать их для реальной навигации нельзя;
- даты распределены по разным сезонам;
- поле cadence добавлено искусственно, чтобы тренировочный набор содержал атрибут, который требуется критериями.

## Состав

Файл tracks.json имитирует список ссылок, который участник получает на старте.

В нём есть:

- 4 маршрута с source=provided — имитация исходных треков;
- 2 маршрута с source=additional — имитация расширения набора данных.

После слияния ветки URL в tracks.json указывают на raw-файлы этого же репозитория, поэтому загрузчик работает именно через HTTP, а не читает GPX напрямую с диска.
