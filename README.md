# Профессионалы — Машинное обучение и большие данные

Учебный репозиторий для подготовки к компетенции **«Машинное обучение и большие данные»** чемпионата «Профессионалы».

Материалы строятся от критериев оценки: сначала разбираем, **за что дают баллы**, затем реализуем минимально достаточное решение.

## Содержание

- Модуль А — сбор и предварительная обработка данных — в разработке.
- Модули Б–Д будут добавляться отдельно.

> В опубликованном комплекте конкурсной документации конкретные исходные треки не приложены. Поэтому для практики используется отдельный тренировочный набор, повторяющий структуру входных данных из задания.
