# Профессионалы — Машинное обучение и большие данные

Учебный репозиторий для подготовки к компетенции **«Машинное обучение и большие данные»** чемпионата «Профессионалы».

Главный принцип подготовки: идём **от критериев оценки**. Сначала определяем, за что начисляются баллы, затем делаем минимально достаточное и проверяемое решение.

## Сейчас готово

### Модуль А — сбор и предварительная обработка данных

- [Пошаговая статья по модулю А](docs/module-a.md)
- [Практический проект](module-a/)
- [Тренировочные входные данные](training-data/)

В модуле А разобраны все **22 балла**: загрузка треков, карты, внешние источники, PostgreSQL без дублей, окружение 500 м, признаки, сезонность, распределения, дополнительные треки, аугментация и отчёт.

Тренировочный проект запускается по этапам или одной командой и специально построен так, чтобы результат каждого шага можно было сразу показать эксперту.

## Важно про данные

В опубликованном комплекте конкурсной документации конкретные исходные треки не приложены. Поэтому в репозитории используется собственный тренировочный набор.

Он **не является официальным набором чемпионата** и не предназначен для навигации. Его задача — воспроизвести структуру входных данных, необходимую для тренировки.
